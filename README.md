# Intelligent Dashboard Using JavaScript

## Project Overview
The Intelligent Dashboard is a web-based project developed using HTML, CSS, and JavaScript. It demonstrates interactive DOM manipulation, event handling, DOM traversal, dynamic UI components, and asynchronous communication with a backend service.

The project combines five JavaScript practical implementations into a single dashboard.

## Objectives
- Process sensor data and identify critical threshold breaches.
- Detect offline intelligent nodes using DOM traversal.
- Demonstrate event capturing and bubbling in nested interactive components.
- Create collapsible sections and dynamically positioned tooltips.
- Fetch and parse JSON data asynchronously and handle errors.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- DOM API
- Fetch API
- Git and GitHub

## Features

### 1. Sensor Alert System
Uses `filter()`, `map()`, and `reduce()` to identify sensor threshold violations and display alerts in an HTML table.

### 2. Offline Node Detection
Uses `NodeIterator` and `TreeWalker` to locate offline nodes and apply warning styles and CSS classes.

### 3. Interactive Chart Event Handling
Demonstrates event capturing, bubbling, click handling, and extraction of event properties.

### 4. Collapsible Sections and Dynamic Tooltips
Creates interactive collapsible content and tooltips that adjust their position according to mouse coordinates and viewport boundaries.

### 5. Asynchronous JSON Data Processing
Uses `fetch()`, `async/await`, JSON parsing, and error handling to retrieve and display backend data.

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.
3. Interact with the dashboard sections to test the features.
4. Ensure an internet connection is available for the external API demonstration.
